## Selected projects

### fmr.fyi

Free Section 8 market-research platform built for a dedicated investor community. Connects HUD FMR and SAFMR lookup, market screening, cash-flow modeling, and saved comparisons. Adds FMR and cash-flow context to Zillow, Redfin, and Realtor.com through a Chrome extension.

Technologies: Next.js, TypeScript, PostgreSQL, Redis

- [Live project](https://fmr.fyi)

### Pokedle

Daily Pokémon guessing game inspired by Wordle. A new Pokémon to identify every day.

Technologies: JavaScript, Node, MongoDB, Express.js

- [Live project](https://pokedle.co)

### BlockLens

Minecraft-inspired voxel modeling for designing unit-block structures as code. Pairs a full web builder with documentation, a CLI, and MCP tools so people and agents can inspect and revise projects from any view.

Technologies: TypeScript, React, Three.js, Node, MCP

- [Live project](https://blocklens-khaki.vercel.app)

### Chrona

Free, local-first video analysis for trimming, splicing, compressing, and exporting lossless PNG frames at any frame rate. Ships with shareable video and frame archives plus an agent-first npm CLI for visually verifying animation.

Technologies: Next.js, TypeScript, WebCodecs, FFmpeg, MCP

- [Live project](https://chrona.fyi)

### pol.ai

ChatGPT-powered experiment that analyzes political bias in text. Highlights potentially biased language and suggests alternative phrasing.

Technologies: TypeScript, Node, MongoDB, Express.js, ChatGPT

- [Live project](https://anthony4834.github.io/polai/)

### Solas

Interactive generative-art experiment built from chords drawn across a circle. Adjust line count, speed, color, and timing as it moves through geometric patterns.

Technologies: React, TypeScript, Canvas, Vite
