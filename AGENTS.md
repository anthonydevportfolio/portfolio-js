# Project delivery rules

-   After every completed code, content, configuration, or design change, validate the affected project, commit all
    task-scoped files, push the commit, and confirm the GitHub Pages deployment succeeds.
-   Do not leave a completed change uncommitted or undeployed unless the user explicitly requests that outcome or an
    external blocker prevents delivery. Report any blocker before stopping.
-   Preserve unrelated user changes. Never stage or commit files outside the current task.
